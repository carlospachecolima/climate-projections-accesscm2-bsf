# climate-projections-accesscm2-bsf
This dataset contains future climate projection maps (Tmin, Tmax, and Precipitation) for the Baixo São Francisco region in Brazil, based on the ACCESS-CM2 climate model (CMIP6) under SSP126, SSP245, SSP370, and SSP585 scenarios, for the periods 2021–2040 to 2081–2100.
